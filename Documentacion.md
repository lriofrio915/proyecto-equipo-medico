📝 Documentación

🛠️ Desarrollo
El proyecto fue construido utilizando Next.js 13+ con App Router, integrando componentes reutilizables en React y usando TailwindCSS para el diseño visual. Se implementó un sistema CRUD básico para administrar productos médicos, permitiendo:

Visualizar productos predefinidos y personalizados.

Buscar por nombre o categoría.

Editar y eliminar productos dinámicamente.

Registrar nuevos productos y persistirlos en localStorage.

Además, se mejoró la experiencia visual con una barra de navegación, footer, botón flotante de WhatsApp y un diseño responsivo optimizado para escritorio y móvil.

🧪 Pruebas realizadas
Durante el desarrollo se realizaron pruebas manuales para verificar:

✅ La carga correcta de los productos base.

✅ La persistencia de datos al registrar productos nuevos.

✅ El funcionamiento del filtro de búsqueda.

✅ La edición y eliminación individual de productos.

✅ El flujo completo desde el registro hasta la visualización.

✅ La redirección automática al home tras registrar.

✅ La correcta visualización de imágenes remotas.

✅ La experiencia en pantallas pequeñas (responsive).

💡 Notas finales
El proyecto puede escalar fácilmente hacia una versión con backend real (Firebase, MongoDB, etc.), autenticación de usuarios y dashboards personalizados. También se puede extender con notificaciones tipo toast, integración de pagos y gestión de inventario en tiempo real.
